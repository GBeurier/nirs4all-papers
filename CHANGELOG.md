# Changelog

All notable changes to **nirs4all-papers** are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project aims to follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). This file was introduced during the
hardening pass; earlier history is in git.

## [Unreleased]

## [0.3.0] - 2026-11-26

- Admit Core 0.7 and SDK 1.7 for the optional document readers.

## [0.2.5] - 2026-11-19

- Adopt the tested Core 0.6 and SDK 1.6 series for optional read-only current-container inspection.
- Preserve exact owner documents, published scores, raw downloads and frozen reproducibility kits;
  Papers does not execute the owners' numerical operations.

## [0.2.3] - 2026-07-06

Patch release for the public deposited-paper archive, site builder (`n4a-papers build`),
provider/export facade, and reproducibility companions.

- Align package, manifest, and citation metadata for the patch-version release candidate.
- Record stricter repository handoff evidence for the forced-best-refit export scenario.
